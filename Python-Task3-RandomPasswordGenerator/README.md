# Random Password Generator

## Oasis Infobyte Python Programming Internship

### Task 3 — Random Password Generator

A command-line password generator developed using Python.

## Features

* Allows the user to choose password length
* Minimum password length of 8 characters
* Supports uppercase letters
* Supports lowercase letters
* Supports numbers
* Supports symbols
* Requires at least two character types
* Validates invalid input
* Generates and displays a password
* Allows the user to generate another password without restarting

## Technologies Used

* Python
* random
* string

## How to Run

1. Make sure Python is installed.
2. Open the project in PyCharm.
3. Run `password_generator.py`.
4. Enter the desired password length.
5. Select the character types.
6. The generated password will be displayed.
