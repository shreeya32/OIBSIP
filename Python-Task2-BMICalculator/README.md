# BMI Calculator

## Oasis Infobyte Python Programming Internship

### Task 2 — BMI Calculator

A beginner-level command-line BMI Calculator developed using Python.

## Features

* Accepts weight in kilograms

* Accepts height in meters

* Calculates BMI using the formula:

  BMI = weight / (height²)

* Classifies BMI into:

  * Underweight
  * Normal
  * Overweight
  * Obese

* Displays BMI rounded to two decimal places

* Handles non-numeric input

* Handles invalid and negative values

* Allows the user to calculate BMI again without restarting the program

## Technologies Used

* Python
* input()
* Basic arithmetic

## How to Run

1. Make sure Python is installed.
2. Open the project in PyCharm.
3. Run `bmi_calculator.py`.
4. Enter your weight and height when prompted.
